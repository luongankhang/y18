# y18 — Colab (上游) vs Dev (本地开发)

## 项目定位

| 名称                         | 说明                                                                                         |
| ---------------------------- | -------------------------------------------------------------------------------------------- |
| **SmartSub（上游 / Colab）** | 开源原项目 [buxuku/SmartSub](https://github.com/buxuku/SmartSub)，社区协作维护、官方 Release |
| **y18（本仓库）**            | 基于 SmartSub 的本地定制分支，应用名、打包 ID、界面品牌为 **y18**                            |

> **Colab** 在此指与上游开源项目的协作关系；**y18 是桌面 Electron 应用**，不是 Google Colab Notebook。

---

## Dev vs Release（两种运行方式）

| 对比项       | **Dev 开发模式**                                 | **Release 发布模式**                   |
| ------------ | ------------------------------------------------ | -------------------------------------- |
| 启动命令     | `yarn dev`                                       | `yarn build:local` 后安装/运行打包产物 |
| 界面标识     | 标题栏显示 **DEV** 徽章                          | 无 DEV 徽章                            |
| 用户数据目录 | `%APPDATA%\y18-dev`（Windows）等，带 `-dev` 后缀 | `%APPDATA%\y18`（正式目录）            |
| 配置/模型    | 与正式版**隔离**，互不影响                       | 用户日常使用数据                       |
| 热重载       | 支持（Next.js + Nextron）                        | 不支持                                 |
| DevTools     | 自动打开                                         | 不打开                                 |
| 环境变量     | 读取 `.env.development.local`                    | 不读取                                 |
| 自动更新     | 不检查 GitHub Release                            | 可检查更新（仍指向上游 SmartSub 仓库） |

### 用户数据路径示例

**Windows**

- Dev: `C:\Users\<用户>\AppData\Roaming\y18-dev`
- Release: `C:\Users\<用户>\AppData\Roaming\y18`

**macOS**

- Dev: `~/Library/Application Support/y18-dev`
- Release: `~/Library/Application Support/y18`

**Linux**

- Dev: `~/.config/y18-dev`
- Release: `~/.config/y18`

## 快速开始（Dev）

```bash
# 1. 安装依赖
yarn install

# 2. （可选）开发环境变量
cp .env.development.local.example .env.development.local

# 3. 准备 whisper addon（Windows/Linux/Intel Mac）
# 下载 addon.node 放到 extraResources/addons/

# 4. 启动开发模式
yarn dev
```

---

## 构建发布版（Release）

```bash
yarn build:local
# 产物在 dist/ 目录，文件名形如 y18_Windows_*.exe
```

## 与上游 SmartSub 的差异

| 项目            | SmartSub 上游          | y18 本仓库             |
| --------------- | ---------------------- | ---------------------- |
| 应用名称        | SmartSub / 妙幕        | **y18**                |
| package name    | smartsub               | **y18**                |
| appId           | com.example.smartsub   | **com.example.y18**    |

---

## 协作建议（Colab 工作流）

1. **跟踪上游**：定期 `git fetch upstream` 合并 SmartSub 新功能
2. **y18 定制**：品牌、语言、本地配置放在本仓库，避免与上游冲突
3. **Dev 调试**：用 `yarn dev` + 独立 `-dev` 数据目录，不污染正式环境
4. **Release 验证**：改完用 `yarn build:local` 打正式包测试后再分发
